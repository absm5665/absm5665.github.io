1. 流变学基础：水泥浆为什么会"流动"

1.1 核心概念图解

剪切应力与剪切速率：推动与响应的关系

基本概念
  • 剪切应力 (τ)：单位面积上的平行驱动力，Pa
  • 剪切速率 (γ̇)：材料内部速度梯度，s⁻¹
  • 牛顿流体：τ与γ̇严格线性关系
  • 非牛顿流体：水泥浆的典型特征
工程意义

施工操作中的实际应用：

  • • 泵送压力计算
  • • 浇筑流动性控制
  • • 振捣能耗优化
"流变学的本质在于描述材料如何响应外力作用。对于水泥基材料，这一学科具有直接的工程意义——新鲜水泥浆、砂浆和混凝土的泵送、浇筑、振捣等施工操作，无不依赖于对其流动行为的精准调控。"

粘度：流动的"阻力系数"

粘度类型 定义 物理意义 典型范围
表观粘度 ηₐₚₚ τ/γ̇（瞬时比值） 特定剪切条件下的流动阻力 0.01–10 Pa·s（强烈剪切依赖）
塑性粘度 μₚ Bingham模型斜率 结构破坏后的纯粘性阻力 0.1–1 Pa·s
零剪切粘度 η₀ γ̇→0时的极限 完全结构化状态的流动阻力 理论上→∞（有屈服应力时）
剪切变稀现象

高剪切速率下表观粘度大幅降低，泵送工况（γ̇ ≈ 100 s⁻¹）下的表观粘度可能仅为静置状态的十分之一。

屈服应力：水泥浆的"启动门槛"

静态屈服应力 τ₀,ₛ

材料从完全静止状态启动的临界应力

50-500 Pa (无减水剂)
动态屈服应力 τ₀,𝒹

结构部分破坏后维持流动所需应力

1-10 Pa (含PCE)
降低幅度

减水剂的作用效果

90-98%

水泥浆屈服应力的微观起源是颗粒间絮凝网络的强度。高效减水剂的加入通过静电斥力与空间位阻效应拆解这一结构，降幅达1-2个数量级。 [1]

1.2 非牛顿流体的世界

剪切变稀：越搅越稀的奥秘

速率指数 n 的意义
材料类型 n值范围 流变行为 工程表现
理想牛顿流体 1.0 线性流动 粘度恒定，与剪切无关
普通水泥浆 0.3–0.7 强剪切变稀 搅拌变稀，静置变稠
高流动性混凝土 0.8–0.95 弱剪切变稀 流动性稳定，易于控制
微观机理

剪切变稀的微观机理：絮凝结构的剪切诱导破坏与颗粒定向排列

低剪切时，颗粒形成各向同性的三维网络，有效体积分数高；高剪切时，水动力克服颗粒间吸引力，网络破坏，颗粒定向排列，粘度随之下降。 [2]

静置恢复

可逆循环

测试方法
滞后环实验
上升曲线与下降曲线围成的面积即为触变性的量度
阶跃剪切协议

粘弹性：固体与液体的双重身份

动态力学测试

储能模量 G' = (τ₀/γ₀)cosδ —— 弹性储存能力

损耗模量 G'' = (τ₀/γ₀)sinδ —— 粘性耗散能力

损耗因子 tanδ = G''/G' —— 粘弹比

行为判据
G' > G''：类固体行为
G' = G''：流动起始
G'' > G'：类液体行为

1.3 经典流变模型

Bingham模型：最简单的塑性流体描述

τ = τ₀ + μₚ·γ̇ (τ > τ₀)
模型特点
  • • 应力低于τ₀时：刚性固体，无流动
  • • 超过τ₀后：牛顿流体方式流动
  • • 参数：τ₀（屈服应力），μₚ（塑性粘度）
工程应用
  • • 泵送压力计算
  • • 模板侧压力估算
  • • 质量控制标准
模型局限性

无法描述剪切变稀行为，实际水泥浆流动曲线通常向下弯曲，直接线性拟合会导致τ₀高估、μₚ低估。

Herschel-Bulkley模型：捕捉剪切变稀的幂律行为

τ = τ₀ + K·γ̇ⁿ
τ₀

屈服应力，零剪切应力截距

K

稠度系数，反映整体粘度水平

n

速率指数，表征剪切变稀程度

模型优势

以三个参数为代价，显著扩展描述能力，成为水泥浆流变研究的首选模型。当n = 1时退化为Bingham模型，n < 1描述剪切变稀。

Casson模型：油墨与巧克力的启发

√τ = √τ₀,𝒸 + √(μ𝒸·γ̇)
模型特点

对低剪切行为的"柔和"描述：当γ̇ → 0时，τ → τ₀,𝒸，但曲线斜率dτ/dγ̇ → ∞，更接近实际材料的渐进屈服特性。

三种模型对比

模型 参数数量 核心特征 最佳适用场景
Bingham 2 线性屈服后流动 工程估算、质量控制
Herschel-Bulkley 3 幂律型剪切变稀 全剪切范围精确描述
Casson 2 渐进屈服，平方根形式 低剪切行为重要时
