# 乡道 · 20:30

坐在四川乡间公路的小皮卡上。晚上八点半，略微破败的水泥路，路边一盏盏泛黄的路灯往后退，远处偶尔有车开着远光过来。可以下车沿着路边走一段。

整个场景是**实时程序化生成**的（three.js / WebGL），不是预渲染的视频或静态模型：路面起伏、裂缝、伸缩缝、砖房、树、竹林、路灯、会车、浮尘、星空、远处的树线剪影，全部在运行时算出来。所有纹理、所有声音都是运行时生成的，**仓库里没有任何图片或音频二进制文件**。

> 这是不含音乐的公开版本。`music/` 目录是空的，点曲目听到的是程序合成的电台垫音。

## 声音

整套声音都走 WebAudio，实时生成，没有一条录音。

**分层**：BGM（收音机）和环境音是两条独立总线，互不盖住。

| 层 | 内容 | 随距离变化 |
|---|---|---|
| 收音机 | 你放进去的歌（或合成垫音） | 是。就在车里时满音量，走开 10 米剩七成，20 米剩三成，30 米外听不见 |
| 环境 | 风、虫鸣、脚下碎石 | 否，一直跟着你 |
| 车内 | 引擎、胎噪 | 只在自己开车时有 |
| 会车 | 迎面的卡车/轿车：引擎 + 胎噪，3D 定位 + 多普勒 | 是，按真实距离 |

会车声音是从车的方向传过来的（`PannerNode`，听者跟着相机）。车迎面来时音调偏高，驶过去就降下来。远处的车先只有低频的闷响，靠近了才听见轮胎碾过水泥的沙沙声。

**音乐**：公开版没有附带任何曲目，`music/` 是空的。想放自己的音乐，就按 `music/README.txt` 里的命名（`01-summer-vibe.mp3` 这一套）把文件放进去，页面启动会自动扫出来。

**收音机的四种状态**

1. 关着 —— 没有音乐也没有垫音，只剩风和虫鸣
2. 开着、未选台 —— 播垫音，音量和放歌时一样大
3. 开着、选了曲目 —— 只播曲目，垫音停
4. 开着、但人走远了听不见 —— 持续 5 秒后补一层**很轻的氛围垫音**（三个高音正弦，缓慢起伏），一走近立刻撤掉

点歌之后垫音立刻响（不让你等探测），后台继续找文件，找到就无缝切到原曲。

声音只做了一点点柔化（去直流 + 高频略收），不做之前那套窄带 + 削波 —— 那套虽然像老喇叭，但把歌压得又薄又刺，不如不放。

## 叫车

下车往路边走远了，画面下方会提示「车在 XX 米外 · 喊一声让它开过来」。按 `C`：

1. 字幕打出「爸，我在这！」
2. 车里没人应声，只有喇叭 —— 一短一长两声
3. 车灯亮起，从远处开过来，引擎声由远及近
4. 停到你旁边，提示「按 E 上车」

人喊的部分没有配音，只有字幕；喇叭声是程序合成的（两个方波过带通）。

## 调试参数

URL 上可以带一些参数，方便复现某个瞬间：

- `?auto` — 跳过开场直接进场景
- `?skip=140` — 直接把车开到 140 m 处
- `?walk` — 以漫步模式开始
- `?sim=30` — 快进 30 秒的模拟
- `?hide=props,veg,cars,road` — 隐藏某一类物体（`beam / lampglow / pool / win / cars / interior / sky / ground / road / truck / dust / insects / mist / stone / truckglow / props / veg`）
- `?probe` — 逐个隐藏场景对象并输出屏幕区域平均亮度（定位异常亮斑用）

## 结构

```
index.html            页面外壳、HUD、收音机界面
js/main.js            场景全部内容（约 2500 行）
js/radio.js           老收音机：播放列表、信号链、合成垫音
js/three.module.js    three r180（本地预览用；线上走 CDN）
js/addons/            BufferGeometryUtils
music/                放音频文件的地方（空）
```

three.js 的加载方式按环境切换：`localhost / 127.0.0.1` 用仓库里的文件（可离线），其他域名走 jsDelivr CDN —— 这样 Pages 上不用塞 2 MB 的库。

## 已知可以继续打磨的地方

- 树冠还是低模团块，近看能看出是二十面体
- 音效（风、引擎、蟋蟀、脚步）都是 WebAudio 实时合成，不是录音
- 路面没有真正的凹陷几何，坑洞是贴花
- 收音机的「信号强度」是装饰性的，没有真的做电台搜索
