把七首歌的音频文件放进这个文件夹，页面会自动认出来。

更快的办法：直接打开页面，把音频文件拖进右下角的收音机，或者点“选本地音频…”。
（这种方式不用改任何文件，但刷新页面后要重新选。）

放进本目录的命名方式（任选一种）：
  01-summer-vibe.mp3
  02-mystery-of-love.mp3
  03-the-hell-song.mp3
  04-chemtrails-over-the-country-club.mp3
  05-so-far-away-acoustic.mp3
  06-closure.mp3
  07-things-you-said.mp3

或者直接用歌曲原名（带空格也行）：
  Summer Vibe (Album Version).mp3

支持的格式：mp3 / m4a / ogg / wav / flac / opus / aac
没有文件也不会静音：页面会播一段程序生成的电台垫音。
